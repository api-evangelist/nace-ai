# Nace.AI — NDI (Nace Document Intelligence)

> NDI is a document-intelligence API that converts any document into
> high-fidelity markdown, classifies its contents against a taxonomy, locates
> values with precise source coordinates, and extracts schema-shaped structured
> JSON. Nace.AI builds specialized AI models and agents (NAVI) that run business
> processes end-to-end on small models enterprises control.
>
> Generated by the API Evangelist enrichment pipeline (2026-07-20) from the
> published OpenAPI (https://ndi-api.nace.ai/openapi.json) and docs. Not an
> official Nace.AI artifact.

## API

- Base URL: https://ndi-api.nace.ai/api/v1
- Auth: X-API-Key header (keys prefixed ndi_sk_)
- Spec: https://ndi-api.nace.ai/openapi.json (OpenAPI 3.1.0)
- Interactive docs: https://ndi-api.nace.ai/docs
- MCP server (remote): https://ndi-api.nace.ai/mcp

## Core operations

- POST /api/v1/upload — stage a document, returns file_id (use ndi://file/<id> as source_url)
- POST /api/v1/parse and /parse_async — convert a document to markdown
- POST /api/v1/ground and /ground_async — locate values, return page/coordinate matches
- POST /api/v1/categorize and /categorize_async — classify segments/sheets against a taxonomy
- POST /api/v1/extract and /extract_async — pull structured JSON matching a caller schema
- GET /api/v1/jobs — list jobs (cursor pagination: limit, cursor, status)
- GET /api/v1/jobs/{job_id} — poll a job (status: pending|running|succeeded|failed)
- POST /api/v1/jobs/{job_id}/cancel — cancel a job
- GET /api/v1/health/load — per-client load probe for self-throttling

## Conventions

- Async pattern: *_async returns 202 { job_id }; poll GET /jobs/{job_id}
- Sync endpoints accept ?timeout_seconds (1-300, default 120); 408/202 means "poll"
- Idempotency: idempotency_key body field (max 128); replay returns the original job
- Correlation: X-Request-Id header, echoed as error.request_id
- Errors: custom envelope { "error": { "code", "message", "request_id" } } (not RFC 9457)
